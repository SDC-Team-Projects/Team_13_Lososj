## COLLECTION TRACKING SYSTEM 

# TEAM №13 (ЛОСОСЬ)

## Goal of this project is to create system for tracking user's collection (collection of coins/poststamps/etc) by topic, displaying status, history and cost
## Target audience is collectors.

Features:
- Adding items
- Categories
- Photos
- Notes
- Cost Estimate

Analytics:
- Total Collection Cost
- Cost of Individual Items
- Category Sorting

Screens:
- Collection List
- Item Card
- Add
- Analytics

Roles: 
- User (collection owner)
- Admin (moderator of categories, status directories, and global statistics)
