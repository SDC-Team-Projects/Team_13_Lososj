# Цель: Реализовать обязательные технические требования.

# Неделя 1: Фундамент и безопасность

[ ] US-001, US-002, US-022: Реализация регистрации и JWT-авторизации (Access + Refresh tokens).

ОЖИДАЛОСЬ:

[ ] US-004, US-005: Создание и просмотр списка коллекций.

[ ] US-006, US-007, US-008: Полный цикл работы с предметами (Создание, чтение, редактирование, удаление).

# Неделя 2 (чт - вс):

# 1)
Backend: Завершить логику JWT.
Frontend: Реализовать AuthContext или сохранение токена в localStorage.

# 2)
Backend: Эндпоинты POST /collections и GET /collections.
Frontend: Доработать валидацию форм входа + привязать кнопку входа к реальному запросу.

# 3)
Backend: Эндпоинты для предметов (CRUD items).
Frontend: Создание коллекций. Сделать так, чтобы при нажатии на «Add collection» в базе реально появлялась запись.

# 4)
Вместе: Проверка «сквозного пути». Регистрация -> Вход -> Создание коллекции -> Отображение её в списке.
Результат: Core-логика закрыта.
