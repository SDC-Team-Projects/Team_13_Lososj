## Roadmap проекта «Система учёта личных коллекций»
# MVP (Недели 1–4)
# Цель: Реализовать обязательные технические требования.

# Неделя 1: Фундамент и безопасность

[ ] Проектирование схемы БД: таблицы пользователей, коллекций и предметов.

[ ] Настройка Backend и подключение к БД.

[ ] US-001, US-002, US-022: Реализация регистрации и JWT-авторизации (Access + Refresh tokens).

[ ] Базовый роутинг на Frontend и формы входа.

# Неделя 2: Core-логика

[ ] US-004, US-005: Создание и просмотр списка коллекций.

[ ] US-006, US-007, US-008: Полный цикл работы с предметами (Создание, чтение, редактирование, удаление).

[ ] US-028, US-029: Реализация окон подтверждения (защита данных).

# Неделя 3: Файлы и структурирование

[ ] US-009: Интеграция загрузки изображений (хранение ссылок в БД).

[ ] US-012, US-015: Категории и детальный просмотр карточки предмета.

[ ] US-025, US-026: Поля состояний и заметок.

# Неделя 4: Аналитика и поиск

[ ] US-011, US-018: Расчет общей стоимости и базовая статистика.

[ ] US-013, US-014: Поиск по названию и фильтрация.

[ ] US-023: Финальная проверка адаптивности интерфейса.

# v1.1 (Недели 5–6)
(На случай, если удастся выиграть время)

[ ] US-016: Экспорт коллекции в файл (CSV/PDF).

[ ] US-017: Генерация публичной ссылки «Поделиться» (Read-only access).

[ ] US-024: Переключатель вида (Сетка/список).

[ ] US-Admin: (Для соответствия 2 ролям) Панель администратора для управления глобальными категориями.

# v1.2+
[ ] Интеграции: API курсов валют для автоматической конвертации стоимости.

[ ] AI-помощник: Автоматическое распознавание предметов по фото.

[ ] Уведомления: Push-уведомления об изменении рыночной цены предметов.
