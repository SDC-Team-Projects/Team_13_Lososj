## US-001: Регистрация пользователя

**Как** новый пользователь    
**Я хочу** зарегистрироваться в системе      
**Чтобы** после регистрации пользователь мог войти в систему и создать/просматривать свои коллекции    

### Критерии приёмки
- [ ] Пользователь может открыть форму регистрации
- [ ] Форма содержит поля email и пароль
- [ ] Пароль должен содержать минимум 8 символов
- [ ] После успешной регистрации создаётся аккаунт пользователя
- [ ] Пользователь получает сообщение об успешной регистрации
