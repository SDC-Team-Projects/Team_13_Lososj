User Stories — Система учёта коллекций

## US-001: Регистрация пользователя

**Как** новый пользователь
**Я хочу** зарегистрироваться в системе
**Чтобы** получить доступ к функциям приложения

### Критерии приёмки
- [ ] Форма с email и паролем
- [ ] Валидация email
- [ ] Пароль минимум 8 символов
- [ ] Подтверждение регистрации

### Критерии приёмки:

- [ ] Подсказка рядом с полем названия, описания, стоимости и состояния

- [ ] Модальное окно с подтверждением удаления

## US-030: Подтверждение изменения данных профиля

**Я хочу** видеть подтверждение после изменения профиля
**Чтобы** быть уверенным, что мои данные обновлены

### Критерии приёмки
- [ ] После сохранения изменений появляется сообщение «Профиль успешно обновлён»
- [ ] Сообщение исчезает через несколько секунд или закрывается пользователем
